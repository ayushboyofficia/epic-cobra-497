# 🐍 Epic Cobra 497

A versatile Telegram bot with multiple features.

## Commands
- /start - Start bot
- /help - Help menu
- /ping - Latency check
- /alive - Status check
- /laugh - Fun
- /magic - 8-ball

## Setup
```bash
pip install -r requirements.txt
python bot.py
```
